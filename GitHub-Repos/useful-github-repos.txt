--------------------------------------------------------------------
  SECTION 1 — UI COMPONENT LIBRARIES
--------------------------------------------------------------------

1. shadcn/ui
   URL:   https://github.com/shadcn-ui/ui
   Stars: ~114k
   WHAT:  Copy-paste component library built on Radix UI + Tailwind CSS.
          Unlike traditional libraries, you own the code — components live
          in your repo. Perfect for GlowUp's custom design system. Includes
          charts, dialogs, tooltips, forms, and 50+ components.
   WHY:   Zero runtime overhead. Pairs perfectly with Tailwind v4 you already use.

2. radix-ui/primitives
   URL:   https://github.com/radix-ui/primitives
   Stars: ~17k
   WHAT:  Headless, fully accessible React UI primitives (Dialog, Dropdown,
          Tooltip, Popover, Accordion, etc.). Unstyled — you bring your own CSS.
          Powers shadcn/ui under the hood.
   WHY:   Handles keyboard nav, screen readers, focus traps — accessibility for free.

3. mantinedev/mantine
   URL:   https://github.com/mantinedev/mantine
   Stars: ~30k+
   WHAT:  React component library with 120+ components and 100+ hooks.
          Full dark/light mode, form management, notifications, modals,
          date pickers, and rich text editor all included.
   WHY:   Best DX of any component lib. The hook collection alone is worth it.

4. heroui-inc/heroui
   URL:   https://github.com/heroui-inc/heroui
   Stars: ~22k+
   WHAT:  Formerly NextUI. Visually stunning React component library built
          on Tailwind CSS and React Aria. Beautiful animations and a modern
          aesthetic that suits apps like GlowUp well.
   WHY:   Gorgeous out-of-the-box styling. Great for gamified/lifestyle apps.

--------------------------------------------------------------------
  SECTION 2 — ANIMATION
--------------------------------------------------------------------

5. motiondivision/motion
   URL:   https://github.com/motiondivision/motion
   Stars: ~28k+
   WHAT:  The official home of Framer Motion (now called "Motion"). Import
          from `motion/react` instead of `framer-motion`. Provides layout
          animations, gestures, scroll animations, and 330+ examples.
   WHY:   You already use framer-motion — this IS the updated package.
          Migrating gives you better tree-shaking and smaller bundles.

--------------------------------------------------------------------
  SECTION 3 — DATA VISUALIZATION & CHARTS
--------------------------------------------------------------------

6. recharts/recharts
   URL:   https://github.com/recharts/recharts
   Stars: ~24k
   WHAT:  Composable charting library built on React + D3. Area, Bar, Line,
          Pie, Radar, Radial charts and more. Already used in GlowUp.
   WHY:   You're already on it — star it and watch releases for v3 updates.

7. apache/echarts
   URL:   https://github.com/apache/echarts
   Stars: ~61k
   WHAT:  Powerful charting and visualization library originally by Baidu.
          Handles massive datasets, 3D charts, heatmaps, and complex
          dashboards. Has a React wrapper: echarts-for-react.
   WHY:   If Recharts hits limits, ECharts scales much further.

8. airbnb/visx
   URL:   https://github.com/airbnb/visx
   Stars: ~19k
   WHAT:  Collection of low-level React + D3 visualization primitives from
          Airbnb. Shapes, scales, axes, grids, legends — all composable.
          Maximum control, zero opinions on styling.
   WHY:   Use this when you need pixel-perfect custom charts (e.g. rank graphs).

--------------------------------------------------------------------
  SECTION 4 — FACE DETECTION & COMPUTER VISION
--------------------------------------------------------------------

9. justadudewhohacks/face-api.js
   URL:   https://github.com/justadudewhohacks/face-api.js
   Stars: ~17k
   WHAT:  JavaScript face detection and recognition API for the browser,
          built on TensorFlow.js. 99.38% accuracy on LFW benchmark.
          Detects age, gender, expressions, landmarks. Already in GlowUp.
   WHY:   Your scan feature relies on this. Watch the repo for model updates.

10. tensorflow/tfjs
    URL:   https://github.com/tensorflow/tfjs
    Stars: ~18k
    WHAT:  TensorFlow for JavaScript — run ML models directly in the browser
           or Node.js via WebGL/WebAssembly. Powers face-api.js under the hood.
           Access to thousands of pre-trained models via TF Hub.
    WHY:   If you expand beyond faces (pose detection, body analysis), use this.

11. serengil/deepface
    URL:   https://github.com/serengil/deepface
    Stars: ~16k
    WHAT:  Python library for face recognition with age, gender, emotion, and
           race analysis. Can be run as an API server that your Next.js app
           calls. More powerful than face-api.js for backend analysis.
    WHY:   If you add a server-side scan or batch analysis feature.

  SECTION 5 — DATABASE & BACKEND
--------------------------------------------------------------------

12. prisma/prisma
    URL:   https://github.com/prisma/prisma
    Stars: ~40k
    WHAT:  Next-gen ORM for Node.js and TypeScript. Prisma Client provides
           type-safe database queries. Supports SQLite, PostgreSQL, MySQL,
           MongoDB, and more. Already the backbone of GlowUp.
    WHY:   You're already using it. Follow this repo for v8+ SQLite improvements.

13. prisma/prisma-examples
    URL:   https://github.com/prisma/prisma-examples
    Stars: ~6k
    WHAT:  Ready-to-run Prisma example projects covering REST, GraphQL,
           fullstack Next.js, authentication, real-time, and more.
    WHY:   Great reference when adding new features (e.g. auth, API routes).

    WHY:   The original next-pwa is no longer actively maintained. This
